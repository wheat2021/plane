## 🎯 解决的问题

### 问题 1: 跨域访问被阻止

**现象**: 前端从公网 IP 访问 API 时，浏览器报 CORS 错误

**原因**:
- 前端环境变量仍使用 localhost
- API 的 CORS 配置未包含公网 IP

**解决方案**:
- ✅ 更新所有前端 .env 文件为公网 IP
- ✅ 重新构建前端服务
- ✅ API CORS 配置已包含公网 IP

### 问题 2: MinIO 连接失败

**现象**: API 日志显示 "Could not connect to the endpoint URL: http://localhost:9000/uploads"

**原因**: API 配置中 MinIO 地址使用 localhost

**解决方案**:
- ✅ 修改为容器服务名 `http://plane-minio:9000`
- ✅ 重启 API 服务

## 🚨 注意事项

### 前端环境变量限制

> [!warning] 重要
> 前端应用使用 Vite 构建，环境变量在**构建时**被内联到 JavaScript bundle 中。
>
> **这意味着**:
> - ❌ 修改 `.env` 后重启**无效**
> - ✅ 必须**重新构建**才能生效

### 容器间通信

确保容器间通信使用正确的地址：

| 通信类型 | 地址格式 | 示例 |
|---------|---------|------|
| 容器内部 | 服务名 | `http://api:8000` |
| 外部访问 | 公网 IP/域名 | `http://107.174.155.181` |

### CORS 配置

修改 CORS 允许的源时，需要：

1. 更新 `apps/api/.env` 中的 `CORS_ALLOWED_ORIGINS`
2. 重启 API 服务：`docker compose restart api`
